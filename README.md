# QSW 现代化个人作品集网站

## 运行方式
1. 解压 `QSW现代化个人作品集.zip`。
2. 双击 `index.html`，或用 VS Code 的 Live Server 打开。
3. 推荐使用较新的 Chrome、Edge、Firefox 浏览器。

## 页面模块
- 首页：个人简介、设计开发方向、访问计数与停留计时、自动日夜主题（按本地时间 07:00–18:59 使用日间模式，其余时间使用夜间模式，也可手动循环切换自动/日间/夜间）。
- 全站浮动“回到顶部”按钮：向下滚动一定距离后显示，点击平滑返回页面顶部；开启系统减少动态效果偏好时改为即时滚动。
- 技能：前端开发、设计、后端基础，支持分类筛选。
- 项目：个人网站、天气应用、电商商品展示、数据可视化概念项目，支持分类筛选与详情弹窗；管理员可新增、编辑、删除项目，设置图片 URL、技术标签，并拖动或按钮排序。项目修改保存在当前浏览器，支持撤销最近一次项目操作。
- 成长：教育经历与成长时间线。
- 生活：摄影、阅读、跑步、音乐、游戏、旅行。
- 注册 / 登录：表单检查、省市区三级联动、身份证 18 位格式与校验码验证。
- 留言：必须注册并登录后发布留言；支持留言类型、时间排序和删除自己的留言。

## 技术说明
- 原生 HTML5、CSS3、JavaScript，无需构建工具或安装依赖。
- CSS Grid / Flexbox、媒体查询、CSS 变量、滚动渐入、卡片悬停层次、页面切换过渡、按钮反馈和 prefers-reduced-motion 支持。
- localStorage 用于演示账号、主题、访问次数和留言；同一浏览器内保存。
- 注册时收集的身份证号、密码、安全答案等均仅保存在当前浏览器，**请勿使用真实敏感信息进行演示**。这不是生产级认证系统；正式部署应改用 HTTPS、服务端认证、密码哈希、数据库与权限控制。
- 省市区联动包含常见地区示例数据，并非完整、实时的全国行政区划数据库。
- 天气、数据可视化卡片是静态概念展示，不连接实时数据服务。
- 视觉动效会尊重系统“减少动态效果”设置；滚动渐入使用 IntersectionObserver，浏览器不支持时不隐藏内容。
- 已对主题模式的无效本地存储值做容错处理，并支持其他标签页修改主题或网站文案后同步刷新。

## 管理员后台（新增）
- 在网站导航中点击“管理后台”。
- 演示管理员账号：`admin`；演示密码：`QswAdmin2026!`。
- 登录后可编辑首页文案、各内容页标题与介绍、技能卡片、项目卡片、成长时间线、兴趣卡片等内容；点击“保存所有更改”后保存在当前浏览器。
- “项目卡片管理”支持新增 / 编辑 / 删除项目，填写名称、说明、分类、日期、图片 URL 和技术标签；支持拖动排序、上移 / 下移与撤销最近一次操作。图片使用公开的 HTTP(S) 地址；不填图片地址时保留原有插画风格。
- 可在后台查看并删除留言；新增关键词搜索、留言类型筛选、筛选结果 CSV 导出；导出时对可能触发电子表格公式的字段做了简单防护。
- 管理后台新增数据概览：注册账户数、留言数、项目卡片数、当前浏览器累计访问次数；这些统计均基于当前浏览器本地数据，不是服务器全站统计。
- “恢复默认内容”会清除本地文案覆盖并重新载入默认页面。
- 管理员会话和 CMS 内容保存在 `localStorage`。此为课程演示功能，前端口令不具备真正的访问控制能力。正式部署请使用服务端管理员认证、密码哈希、服务端权限检查、数据库与审计日志，并避免把密码、身份证号等敏感信息放在浏览器本地存储。

## 数据备份与恢复（新增）
- 管理员登录后，可在“数据备份与恢复”区域导出完整 JSON 备份，或选择有效的 QSW 备份文件恢复。
- 备份包含注册账户、留言、项目、网站文案、主题设置和访问次数；不会保存管理员登录会话，恢复后普通用户需要重新登录。
- 导入前会校验备份标识、版本、数据类型与数量上限，并在覆盖前要求确认；单个备份文件最大 20 MB。
- **备份文件可能包含姓名、电话、邮箱、身份证号、密码和安全问题答案等敏感信息。请使用虚构演示数据，并将备份保存在安全位置。**
- 备份恢复仅适用于当前浏览器的本地演示数据；它不是服务端数据库迁移或生产环境灾备方案。

## 最终验收与使用边界
- 导入备份时会进一步检查用户名格式、重复用户名、账户字段长度、留言内容长度与项目字段长度，降低异常 JSON 覆盖本地数据的风险。
- 建议验收顺序：打开首页 → 切换日/夜/自动主题 → 注册演示账号 → 登录并发布留言 → 删除自己的留言 → 管理员登录 → 修改文案与项目 → 导出备份 → 在测试数据上恢复备份 → 刷新页面确认数据仍在。
- 交付检查包括 JavaScript 语法、HTML 结构与重复 ID、资源路径、CSS 大括号配对、ZIP 完整性。由于项目是纯前端静态网站，仍需在目标浏览器中人工完成以上交互验收。
- 安全结论：当前版本适合作为个人作品集与课程演示。管理员密码写在前端代码中，普通用户密码和身份证等字段存储于 localStorage；任何有能力访问浏览器开发者工具或本地文件的人都可能读取或修改这些数据。不要部署为真实用户服务，也不要输入真实敏感信息。
